# Carpeta de Códigos y Recursos (/src)

Este directorio contiene los entregables técnicos organizados del proyecto **Termopaneles El Monte**.

## Estructura de la Carpeta

* **[flujo/](file:///c:/Users/Javiera%20Carrizo/OneDrive/Documentos/Demo%20agentic/src/flujo/)**: Archivo exportado del flujo de automatización de n8n en formato JSON.
* **[prompts/](file:///c:/Users/Javiera%20Carrizo/OneDrive/Documentos/Demo%20agentic/src/prompts/)**: Prompts utilizados en el chatbot de IA y guías para su configuración.
* **[inventario/](file:///c:/Users/Javiera%20Carrizo/OneDrive/Documentos/Demo%20agentic/src/inventario/)**: Mapeo de columnas y reglas de negocio del stock disponible.
* **[docs/](file:///c:/Users/Javiera%20Carrizo/OneDrive/Documentos/Demo%20agentic/src/docs/)**: Documentación complementaria técnica y arquitectónica.

> [!NOTE]
> El código fuente del frontend (`index.html`, `app.js`, `index.css` y assets de imágenes) se mantiene directamente en la raíz `/` para garantizar la compatibilidad con el despliegue automático continuo en Vercel, el cual busca un punto de entrada estático en la raíz del repositorio.
